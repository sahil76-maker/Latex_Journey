# LaTeX Journey

A structured learning repository documenting my journey of learning LaTeX through practical examples, exercises, and projects.

## About This Repository

This repository contains my LaTeX learning materials based on lectures taught at **Malaviya National Institute of Technology (MNIT), Jaipur**.

The objective is to understand LaTeX concepts, implement them through practical examples, and develop the ability to create professionally formatted technical documents.

## Learning Objectives

- Understand the fundamentals of LaTeX.
- Learn document structure and formatting.
- Write mathematical equations and expressions.
- Create tables, figures, and diagrams.
- Work with different LaTeX environments.
- Develop professional academic and technical documents.

## Learning Roadmap

| No. | Module | Topics |
|---|---|---|
| 01 | Introduction to LaTeX | Basics, tools, compilation and document structure |
| 02 | Document Formatting | Text formatting, sections and page layout |
| 03 | Mathematical Typesetting | Equations, symbols, arrays and matrices |
| 04 | Lists and Environments | Itemize, enumerate and other environments |
| 05 | Tables | Tabular, multicolumn, multirow and references |
| 06 | Colours and Figures | Colours, images and picture environment |
| 07 | Advanced Documents | Document classes, page styles and bibliography |
| 08 | Practice Exercises | Concept-wise exercises and solutions |
| 09 | Mini Projects | Practical implementations |
| 10 | Final Project | Complete technical documentation |
